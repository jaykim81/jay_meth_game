# 루나의 수학 모험 · JAY MATH

아이폰 가로 화면과 아이패드에서 즐기는 2D 수학 전투 웹게임입니다. 플레이어 대 몬스터 방식이며, 초등 1~6학년마다 6개 단계가 있습니다.

## 실행

Node.js 22 이상과 Python 3이 있으면 별도 의존성 설치 없이 실행합니다.

```sh
npm test
npm run serve
```

브라우저에서 `http://localhost:4173`을 엽니다. 실제 iPhone/iPad Safari 검증은 별도로 필요합니다.

## 게임 규칙

- 학년 → 단계 → 모험 시작. 각 단계에서 3라운드를 승리하면 완료됩니다.
- 제한 시간 안에 정답 입력 후 공격 버튼 또는 Enter를 누르면 공격합니다.
- 제한 시간의 35% 이내에 정답이면 크리티컬, 3연속 정답마다 추가 피해가 적용됩니다.
- 오답이나 시간 초과 시 피해를 받고 정답을 2.1초 동안 확인합니다.
- 분수 `1/2`와 소수 `0.5` 등 같은 값은 정답으로 처리합니다. 문자, 연산식, 0으로 나누기는 허용하지 않습니다.
- 다음 문제를 미리 볼 수 있습니다. 전투 일시정지 및 다른 앱으로 전환 시 문제 시간이 멈춥니다.
- 정답, 라운드 승리, 단계 완료로 경험치를 얻습니다. 레벨업 시 공격력 +1(최대 +12), 체력 15 회복.
- 레벨 1→2에 경험치 100이 필요하며 이후 필요 경험치는 레벨당 40씩 증가합니다.
- JAY RPG 기존 아이디·비밀번호로 로그인하면 경험치와 학년·단계별 별/최고 점수/최고 콤보를 Supabase에 저장합니다. 다른 기기에서 같은 계정으로 로그인해 이어할 수 있습니다.
- 로그인 없이 연습할 수도 있습니다. 연습 기록은 이 기기에 남으며, 로그인 후 계정 메뉴에서 명시적으로 가져올 수 있습니다. 경험치는 더 큰 값을 사용해 중복 합산하지 않습니다.
- 세션 토큰·비밀번호는 메모리에만 보관합니다. 새로고침하면 다시 로그인합니다. 미전송 기록은 사용자별 localStorage 백업에 보관하고 재시도합니다.
- 다른 기기가 저장해 revision이 바뀌면 플레이를 일시정지합니다. 최신 기록 불러오기를 누르면 서버 기록을 사용하고 이전 미전송 기록은 별도 로컬 백업에 남깁니다.

## 학습 내용

1학년: 10/20까지 덧셈·뺄셈, 받아올림 없는 두 자리 수 계산.
2학년: 두 자리 수 덧셈·뺄셈과 구구단.
3학년: 세 자리 수, 두 자리 수 곱셈, 나눗셈, 길이 단위, 분수의 의미.
4학년: 큰 수, 두 자리 수 나눗셈, 같은 분모 분수, 소수, 각도.
5학년: 최대공약수, 다른 분모 분수, 분수·소수 곱셈, 넓이, 평균.
6학년: 분수·소수 나눗셈, 비율·백분율, 부피, 원의 넓이·둘레(π=3.14).

학년별 대표 연산을 구현한 첫 버전입니다. 교과서의 모든 단원·문제 유형을 담은 것은 아닙니다.

## 파일

- `dist/index.html`, `dist/style.css`: 지도, 전투, 모바일 UI.
- `dist/game.js`: 전투 상태, 입력, 애니메이션, 저장, 경험치 반영.
- `dist/math.js`: 36단계 문제 생성 및 정답 검증.
- `dist/progression.js`: 경험치와 레벨 계산.
- `dist/account.js`: 기존 JAY RPG 인증, 수학게임 전용 RPC, 저장/갱신/충돌/계정별 백업.
- `db/math-account.sql`: 적용된 수학게임 테이블·RLS·RPC 스키마. 원본 RPG 테이블은 수정하지 않습니다.
- `tests/account.test.mjs`: 공유 아이디 규칙, 저장 순서, 인증 갱신, 오류/충돌 및 계정 분리 테스트.
- `dist/assets/`: 전투용 이미지 2종.
- `tests/math.test.mjs`: 5,400개 생성 문제, 동치 정답, 크리티컬/콤보, 레벨 경계 검증.

## 그림 및 배포

`jaykim81/jayrpg1`의 루나·오크·해골 컨셉 이미지를 참고해 전투용 2D 캐릭터 아틀라스와 숲 배경을 새로 생성했습니다. 기존 Unity 모델이나 원본 코드는 수정하지 않았습니다. 배경 및 6종 캐릭터는 정적 이미지이며, 공격/피격/대기 동작은 CSS 애니메이션입니다.

`dist`는 정적 웹호스팅에 바로 배포할 수 있습니다. Sites 프로젝트 식별자는 `.openai/hosting.json`에 있습니다. GitHub Pages를 사용할 경우 저장소 Pages 설정에서 `gh-pages` 브랜치의 `/ (root)`를 선택하세요.


## 계정·DB

기존 `jayrpg` Supabase 프로젝트의 Auth 및 `game_profiles`를 사용합니다. 아이디를 정규화한 SHA-256 값에 `@id.jayrpg.invalid`를 붙이는 기존 계정 규칙과 동일합니다. 수학게임에서는 회원가입이나 계정 인증 설정을 변경하지 않습니다.

`math_profiles`는 사용자 ID, 누적 경험치, revision을 저장합니다. 레벨은 경험치에서 계산합니다. `math_stage_records`는 사용자·학년·단계 복합 기본키로 별/최고 점수/최고 콤보를 저장합니다. 두 테이블은 RLS로 본인 조회만 허용하고 직접 쓰기는 금지합니다. `save_math_state`가 소유자 및 payload 검증, revision 비교, 단일 트랜잭션 저장을 수행합니다. `load_math_state`는 일관된 스냅샷을 반환합니다.

공개 RPC는 SECURITY INVOKER이며, 쓰기 트랜잭션의 SECURITY DEFINER 함수는 API 비노출 `math_private` 스키마에 있고 auth.uid()로만 소유자를 결정합니다. 클라이언트에는 publishable key만 포함합니다. 클라이언트가 계산한 게임 수치를 저장하므로 경쟁 랭킹을 위한 서버 문제/점수 판정은 별도 구현이 필요합니다.
