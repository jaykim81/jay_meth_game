# 루나의 수학 모험 · JAY MATH

아이폰 가로 화면과 아이패드에서 즐기는 2D 수학 전투 웹게임입니다. 플레이어 대 몬스터 방식이며, 초등 1~6학년마다 6개 단계가 있습니다.

## 실행

Node.js 22 이상과 Python 3이 있으면 별도 의존성 설치 없이 실행합니다.

```sh
npm test
npm run serve
```

브라우저에서 `http://localhost:4173`을 엽니다. 실제 iPhone/iPad Safari 검증은 별도로 필요합니다.

## 게임 규칙

- 학년 → 단계 → 모험 시작. 각 단계에서 3라운드를 승리하면 완료됩니다.
- 제한 시간 안에 정답 입력 후 공격 버튼 또는 Enter를 누르면 공격합니다.
- 제한 시간의 35% 이내에 정답이면 크리티컬, 3연속 정답마다 추가 피해가 적용됩니다.
- 오답이나 시간 초과 시 피해를 받고 정답을 2.1초 동안 확인합니다.
- 분수 `1/2`와 소수 `0.5` 등 같은 값은 정답으로 처리합니다. 문자, 연산식, 0으로 나누기는 허용하지 않습니다.
- 다음 문제를 미리 볼 수 있습니다. 전투 일시정지 및 다른 앱으로 전환 시 문제 시간이 멈춥니다.
- 정답, 라운드 승리, 단계 완료로 경험치를 얻습니다. 레벨업 시 공격력 +1(최대 +12), 체력 15 회복.
- 레벨 1→2에 경험치 100이 필요하며 이후 필요 경험치는 레벨당 40씩 증가합니다.
- 단계의 별/최고 점수 및 누적 경험치는 브라우저 localStorage에 저장됩니다. 다른 기기와 동기화되지 않습니다.

## 학습 내용

1학년: 10/20까지 덧셈·뺄셈, 받아올림 없는 두 자리 수 계산.
2학년: 두 자리 수 덧셈·뺄셈과 구구단.
3학년: 세 자리 수, 두 자리 수 곱셈, 나눗셈, 길이 단위, 분수의 의미.
4학년: 큰 수, 두 자리 수 나눗셈, 같은 분모 분수, 소수, 각도.
5학년: 최대공약수, 다른 분모 분수, 분수·소수 곱셈, 넓이, 평균.
6학년: 분수·소수 나눗셈, 비율·백분율, 부피, 원의 넓이·둘레(π=3.14).

학년별 대표 연산을 구현한 첫 버전입니다. 교과서의 모든 단원·문제 유형을 담은 것은 아닙니다.

## 파일

- `dist/index.html`, `dist/style.css`: 지도, 전투, 모바일 UI.
- `dist/game.js`: 전투 상태, 입력, 애니메이션, 저장, 경험치 반영.
- `dist/math.js`: 36단계 문제 생성 및 정답 검증.
- `dist/progression.js`: 경험치와 레벨 계산.
- `dist/assets/`: 전투용 이미지 2종.
- `tests/math.test.mjs`: 5,400개 생성 문제, 동치 정답, 크리티컬/콤보, 레벨 경계 검증.

## 그림 및 배포

`jaykim81/jayrpg1`의 루나·오크·해골 컨셉 이미지를 참고해 전투용 2D 캐릭터 아틀라스와 숲 배경을 새로 생성했습니다. 기존 Unity 모델이나 원본 코드는 수정하지 않았습니다. 배경 및 6종 캐릭터는 정적 이미지이며, 공격/피격/대기 동작은 CSS 애니메이션입니다.
